# Campus Notes Hub

A multi-page website to organise subject-wise notes for classmates, with navigation and a search feature.

## Live Demo
https://palakagrawal2428-ai.github.io/campus-notes-hub/

## Pages
- Home
- Subjects (Python, DBMS, Networking) with search box
- About
- Contact (form)

## Features
- Navigation bar linking all pages
- Search box that filters subjects as you type
- Responsive layout for mobile and laptop

## Tech Used
HTML, CSS, JavaScript
